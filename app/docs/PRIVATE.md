# Documentação privada

Este repositório é público. Decisões (`decisions.md`), dívidas técnicas (`tech-debt.md`), checklist de deploy (`deploy-checklist.md`), auditorias (`audits/`), fotos de produção (`as-is/`) e as specs das features (`tasks/`) vivem fora dele, em `../private/backend/` (`~/hous3/vesta/private/backend/`), ao lado do clone.

O que vai pra lá: qualquer coisa que cite cliente, pessoa, termo comercial, conta AWS ou fraqueza ainda não corrigida. O `AGENTS.md` (seção "Private documentation") é o contrato e vale para tudo que é commitado, inclusive mensagens de commit e texto de PR: cliente é "o cliente em produção", pessoa é o papel dela. O `.gitignore` impede que os caminhos voltem e o `code-reviewer` confere o resto.
